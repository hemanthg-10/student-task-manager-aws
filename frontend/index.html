Enterprise Architecture

Crafted with Clean Standards

Student Task Manager is structured as a decoupled frontend client prepared for high-availability cloud deployment with a Python Flask REST API and an AWS Application Load Balancer.

Semantic HTML5 Modular CSS3 Vanilla ES6+ JS Bootstrap 5.3 AWS ALB Ready

System Architecture Flow

1. Frontend Client: Responsive Vanilla JS UI with centralized API abstraction layer.
2. Application Load Balancer: AWS ALB routing requests securely to backend nodes.
3. Python Flask REST API: Stateless endpoints handling authentication, tasks, and metrics.
